# Fenru 사용 안내

Fenru는 자료와 학습 기록을 내 기기에 보관합니다. 현재 버전은 개발 프리릴리스이며 AI, Google Drive 자동 동기화, 네이티브 위젯은 제공하지 않습니다.

## 첫 자료 추가
홈 또는 라이브러리 → 파일 가져오기를 누르세요. Windows에서는 파일을 끌어 놓을 수도 있습니다. 원본은 변경하지 않으며 작업 공간에 복사합니다. 같은 내용의 로컬 파일은 중복 저장하지 않습니다.

## PDF 읽기
자료를 누르면 PDF 뷰어가 열립니다. 텍스트 선택·복사는 PDF 뷰어의 기본 메뉴를 사용하세요. 상단 페이지 번호를 누르면 페이지를 지정할 수 있습니다. 확대는 마우스/터치 제스처를 사용합니다. 마지막 페이지는 이동 후 자동 저장됩니다.
책갈피 버튼은 현재 페이지를 보관합니다. 메모 버튼으로 페이지 메모를 작성하세요. 오른쪽 주석 목록 또는 휴대폰의 주석 버튼에서 이동·수정·삭제합니다. 텍스트 영역 형광펜과 AI 질문 메뉴는 아직 구현되지 않았습니다.

## 노트
노트 → 새 노트를 누르거나 자료 메뉴 → 연결된 노트 만들기를 사용하세요. Markdown을 입력하면 잠시 후 자동 저장됩니다. 미리보기 버튼으로 제목·목록·표·코드 블록을 확인합니다. 저장 실패 시 화면을 닫지 말고 저장 버튼으로 재시도하세요.

## 정리와 검색
자료 메뉴에서 이름·폴더·태그를 수정할 수 있습니다. 원본 파일명과 문서 ID는 유지됩니다. 상단 검색은 제목·태그·텍스트 자료와 노트 내용을 검색합니다. PDF 본문 인덱싱은 아직 제공되지 않습니다. 길게 누르거나 메뉴의 선택으로 여러 자료를 휴지통에 이동할 수 있습니다.

## Canvas 연결
학교 Canvas 웹사이트 → 계정 → 설정 → 승인된 통합/새 액세스 토큰에서 개인 토큰을 발급하세요. 학교 정책상 발급이 불가능할 수 있습니다. Fenru 설정 → Canvas 연결에서 HTTPS 기본 주소와 토큰을 입력합니다. 비밀번호는 입력하지 않습니다. 연결 후 과목 → Canvas 자료 가져오기에서 과목을 선택합니다. 현재 파일과 과제를 가져옵니다. 변경된 파일은 별도 버전으로 보관하며 이전 주석을 삭제하지 않습니다.
401: 토큰 확인/재발급. 403: 접근 권한 확인. 404: 주소 확인. 429: 잠시 후 재시도. 일부 학교의 리다이렉트 기반 다운로드는 이 버전에서 지원하지 않습니다. 실패 전에 가져온 자료는 유지됩니다. 자동 백그라운드 가져오기는 지원하지 않습니다.

## 일정
플래너에서 일정을 추가하고 날짜를 선택하세요. 완료 체크는 자동 저장됩니다. Canvas 과제도 표시됩니다. 이 버전은 시스템 알림을 예약하지 않습니다.

## 백업 및 다른 기기로 이동
설정 → ZIP 백업으로 작업 공간을 내보내세요. 다른 기기에서 설정 → 백업 병합 복원을 사용합니다. 기존 항목과 비교하여 새 버전을 적용하고 동시에 수정한 항목은 충돌 복사본으로 보관합니다. 복원 전에 별도 백업을 권장합니다. 지원하는 백업 최대 크기는 압축/해제 각각 1GB입니다. ZIP은 암호화되지 않으며 개인 문서가 포함됩니다. 비밀 키와 연결 토큰은 포함되지 않습니다.

## 삭제와 복구
자료 삭제는 휴지통 이동입니다. 라이브러리 → 휴지통 → 항목 메뉴 → 복구를 사용하세요. 원본 파일과 백업 파일은 삭제하지 않습니다.

## 개인정보
사용자 추적·광고 SDK가 없습니다. Canvas 연결 토큰은 운영체제 보안 저장소에 저장합니다. 설정에서 연결을 해제할 수 있습니다. AI 연결이 없는 이 버전은 학습자료를 AI로 전송하지 않습니다. Google Drive 동기화도 동작하지 않습니다.

## 문제 해결
저장 실패: 기기 여유 공간과 폴더 접근 권한을 확인하세요. 앱을 지우거나 데이터를 초기화하지 마세요.
외부 앱 열기 실패: 파일 형식을 지원하는 앱을 설치하세요. DOCX·PPTX·XLSX 등은 외부 앱이 필요합니다.
깨진 PDF: 원본 파일을 다른 뷰어에서 확인하세요. 스캔 PDF는 OCR 텍스트 선택을 지원하지 않습니다.
업데이트: 같은 서명의 Android APK로 업데이트하세요. Windows는 앱을 종료한 뒤 새 배포 파일로 교체합니다. 작업 공간은 실행 파일과 별도로 보관됩니다.

## 단축키
Ctrl+K 검색, Ctrl+O 파일 가져오기, Ctrl+N 새 노트.

## 아직 제공하지 않는 기능
OpenAI·DeepSeek 연결 및 모델 선택/비용 관리, Google Drive OAuth 및 자동 동기화, PDF 영역 하이라이트·OCR·출처 기반 AI 검색, 노트 백링크·수식, Android 공유 인텐트·홈 위젯·일정 알림, Windows 트레이·파일 연결, 영어 UI 전체 번역. 요구사항 구현이 완료된 제품으로 간주하지 마세요.
