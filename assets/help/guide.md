# Fenru 사용 안내

Fenru는 자료와 학습 기록을 내 기기에 보관합니다. 현재 버전은 개발 프리릴리스이며 Google Drive 자동 동기화와 네이티브 위젯은 제공하지 않습니다. AI는 사용자의 별도 API 키가 필요합니다.

## 첫 자료 추가
홈 또는 라이브러리 → 파일 가져오기를 누르세요. Windows에서는 파일을 끌어 놓을 수도 있습니다. 원본은 변경하지 않으며 작업 공간에 복사합니다. 같은 내용의 로컬 파일은 중복 저장하지 않습니다.

## PDF 읽기
자료를 누르면 PDF 뷰어가 열립니다. 텍스트 선택·복사는 PDF 뷰어의 기본 메뉴를 사용하세요. 상단 페이지 번호를 누르면 페이지를 지정할 수 있습니다. 확대는 마우스/터치 제스처를 사용합니다. 마지막 페이지는 이동 후 자동 저장됩니다.
책갈피 버튼은 현재 페이지를 보관합니다. 메모 버튼으로 페이지 메모를 작성하세요. 오른쪽 주석 목록 또는 휴대폰의 주석 버튼에서 이동·수정·삭제합니다. 텍스트를 선택한 뒤 컨텍스트 메뉴 또는 더보기 → 선택 영역 하이라이트/밑줄을 사용하세요. 주석은 재실행 후에도 유지됩니다. 더보기 → PDF 본문 검색으로 검색하고 다음 결과로 이동합니다.

## 노트
노트 → 새 노트를 누르거나 자료 메뉴 → 연결된 노트 만들기를 사용하세요. Markdown을 입력하면 잠시 후 자동 저장됩니다. 미리보기 버튼으로 제목·목록·표·코드 블록을 확인합니다. 저장 실패 시 화면을 닫지 말고 저장 버튼으로 재시도하세요.

## 정리와 검색
자료 메뉴에서 이름·폴더·태그를 수정할 수 있습니다. 원본 파일명과 문서 ID는 유지됩니다. 상단 검색은 제목·태그·텍스트 자료와 노트 내용을 검색합니다. PDF 본문 인덱싱은 아직 제공되지 않습니다. 길게 누르거나 메뉴의 선택으로 여러 자료를 휴지통에 이동할 수 있습니다.

## Canvas 연결
학교 Canvas 웹사이트 → 계정 → 설정 → 승인된 통합/새 액세스 토큰에서 개인 토큰을 발급하세요. 학교 정책상 발급이 불가능할 수 있습니다. Fenru 설정 → Canvas 연결에서 HTTPS 기본 주소와 토큰을 입력합니다. 비밀번호는 입력하지 않습니다. 연결 후 과목 → Canvas 자료 가져오기에서 과목을 선택합니다. 현재 파일과 과제를 가져옵니다. 변경된 파일은 별도 버전으로 보관하며 이전 주석을 삭제하지 않습니다.
401: 토큰 확인/재발급. 403: 접근 권한 확인. 404: 주소 확인. 429: 잠시 후 재시도. HTTPS CDN 리다이렉트는 처리하지만 학교 외부로 Canvas 토큰을 전달하지 않습니다. HTTP 다운그레이드나 반복 경로는 거부합니다. 실패 전에 가져온 자료는 유지됩니다. 자동 백그라운드 가져오기는 지원하지 않습니다.

## 일정
플래너에서 일정을 추가하고 날짜를 선택하세요. 완료 체크는 자동 저장됩니다. Canvas 과제도 표시됩니다. 이 버전은 시스템 알림을 예약하지 않습니다.

## 백업 및 다른 기기로 이동
설정 → ZIP 백업으로 작업 공간을 내보내세요. 다른 기기에서 설정 → 백업 병합 복원을 사용합니다. 기존 항목과 비교하여 새 버전을 적용하고 동시에 수정한 항목은 충돌 복사본으로 보관합니다. 복원 전에 별도 백업을 권장합니다. 지원하는 백업 최대 크기는 압축/해제 각각 1GB입니다. ZIP은 암호화되지 않으며 개인 문서가 포함됩니다. 비밀 키와 연결 토큰은 포함되지 않습니다.

## 삭제와 복구
자료 삭제는 휴지통 이동입니다. 라이브러리 → 휴지통 → 항목 메뉴 → 복구를 사용하세요. 원본 파일과 백업 파일은 삭제하지 않습니다.

## 개인정보
사용자 추적·광고 SDK가 없습니다. Canvas 토큰과 AI 키는 운영체제 보안 저장소에 저장합니다. 설정에서 연결을 해제할 수 있습니다. AI 질문 시 최근 메시지 최대 20개가 제공자에 전송되고 문서 포함 스위치를 켜면 선택한 텍스트 또는 현재 페이지도 전송됩니다. Google Drive 동기화는 아직 동작하지 않습니다.

## 문제 해결
저장 실패: 기기 여유 공간과 폴더 접근 권한을 확인하세요. 앱을 지우거나 데이터를 초기화하지 마세요.
외부 앱 열기 실패: 파일 형식을 지원하는 앱을 설치하세요. DOCX·PPTX·XLSX 등은 외부 앱이 필요합니다.
깨진 PDF: 원본 파일을 다른 뷰어에서 확인하세요. 스캔 PDF는 OCR 텍스트 선택을 지원하지 않습니다.
업데이트: 같은 서명의 Android APK로 업데이트하세요. Windows는 앱을 종료한 뒤 새 배포 파일로 교체합니다. 작업 공간은 실행 파일과 별도로 보관됩니다.

## 단축키
Ctrl+K 검색, Ctrl+O 파일 가져오기, Ctrl+N 새 노트.

## 아직 제공하지 않는 기능
Google Drive OAuth 및 자동 동기화, OCR·전체 라이브러리 PDF RAG, 노트 백링크·수식, Android 공유 인텐트·홈 위젯·일정 알림, Windows 트레이·파일 연결, 영어 UI 전체 번역. 요구사항 구현이 완료된 제품으로 간주하지 마세요.

## AI 키와 문서 질문
설정 → AI API 키·모델 설정에서 OpenAI 또는 DeepSeek를 선택하고 새 키를 입력하세요. 빈칸이면 기존 키를 유지합니다. 연결 확인·모델 조회 후 텍스트 생성 모델을 선택하거나 모델 ID를 직접 입력한 뒤 저장하세요. ChatGPT 구독과 API 과금은 별개입니다. 키는 채팅·이슈에 올리지 마세요.
과목 → 과목 열기에서 자료 목록과 과목 질문을 함께 사용합니다. PDF 리더 상단 ‘자료 질문’이나 라이브러리 자료 메뉴의 ‘이 자료에 질문’을 사용하세요. 과목·자료별 대화는 분리되어 이어집니다. 넓은 화면은 오른쪽 패널, 좁은 화면은 해당 범위의 질문 화면을 엽니다. PDF는 자료 전체/현재 페이지/선택 문장을 고를 수 있고 선택 문장 질문은 입력 중 선택이 풀려도 원문을 보존합니다.
자료 전체/과목 질문은 PDF·텍스트 본문을 기기에서 키워드 검색하고 관련 발췌 최대 6개/12,000자를 선택합니다. 참고 미리보기는 유료 API를 호출하지 않습니다. 스캔 OCR과 PPTX/DOCX 추출, 의미 검색, 완전한 전체 요약은 지원하지 않습니다. 답변의 출처 버튼으로 실제 문서 페이지를 열 수 있습니다. 읽지 못한 자료는 제외 사유로 안내합니다. 원본 버전별 텍스트 캐시는 로컬에 저장하며 백업 ZIP에서 제외됩니다.
생성 중 정지 버튼으로 취소할 수 있고 부분 답변은 보관됩니다. 답변 옆 버튼으로 복사하거나 노트로 저장합니다. 대화는 재실행 후 이어집니다. 검색에서 이전 대화 내용을 찾을 수 있습니다. 일별 기록 토큰 상한과 요청별 출력 한도는 설정할 수 있지만 금액 예산이 아니며 실패/취소 시 사용량이 누락될 수 있습니다. 실제 청구는 제공자 대시보드에서 확인하세요.
401은 키 인증 실패, 403은 모델 권한 부족, 429는 잔액·요청 한도 등을 확인합니다. 유료 요청은 자동 재시도하지 않습니다.


## PDF 읽기 도구
페이지/목차/주석 버튼에서 페이지 미리보기와 저장한 주석으로 이동합니다. 도구 막대에는 확대/축소, 너비/한 페이지 맞춤, 본문 검색과 결과 이동, 페이지 메모가 있습니다. 따뜻하게/야간 읽기와 주석 색상은 설정을 기억합니다. PDF 원본은 바꾸지 않습니다. 주석 Undo/Redo는 현재 리더 실행 중 만든 선택 영역 주석에 적용되며, 이전 주석은 목록에서 수정·휴지통·복구할 수 있습니다. Ctrl+F 검색, Ctrl +/- 확대/축소, Ctrl+0 너비 맞춤을 사용하세요.


## 필기와 정리 노트 (alpha.7)
PDF 도구줄의 읽기 메뉴 → 펜 필기 / 자유 형광펜 / 직선 밑줄을 선택하고 페이지에 드래그하세요. 색상과 굵기를 고를 수 있습니다. 페이지 이동·텍스트 선택은 읽기 모드로 전환하세요. 주석 목록에서 삭제하고 현재 실행 중 만든 주석은 Undo/Redo할 수 있습니다. 필기는 원본에 합쳐 쓰지 않고 별도로 저장하며 ZIP 백업에 포함됩니다.
상단 정리 노트 버튼은 같은 자료의 정리본을 이어 씁니다. 넓은 창에서는 PDF 옆에 편집기가 열리고 자동 저장 상태를 표시합니다. 작은 창에서는 노트 화면으로 이동합니다. 질문 버튼으로 다시 질문 패널을 선택합니다.

## 질문 화면과 노트 저장 (alpha.7)
대화 메뉴에서 참고 범위·모델, 이전 대화, 연결된 학습 노트를 엽니다. 입력창 왼쪽 +는 설명/정리/한 문제씩 복습 도구이며 선택 후 전송 버튼을 눌러야 요청합니다. Ctrl+Enter로 전송할 수 있습니다. 노트로 저장 성공 시 메시지와 열기 버튼을 표시하고, 다시 누르면 같은 노트를 엽니다. 저장한 답변의 출처도 노트에서 확인할 수 있습니다.

## 자동 PDF 변환 (alpha.7)
새 Office/한글 자료를 가져올 때 원본을 먼저 저장하고 로컬 변환을 시도합니다. Windows에 LibreOffice 또는 해당 Word/PowerPoint/한글이 설치되어 있어야 합니다. 한글은 파일 접근 허용이 필요할 수 있습니다. Android에는 변환 엔진이 없습니다. 실패해도 원본은 유지되며 자료 화면에서 PDF로 변환·재시도할 수 있습니다. 변환된 자료를 열면 PDF 리더를 사용합니다. 원본은 라이브러리에서 그대로 보관됩니다.
Canvas는 파일·주차 자료 외에 페이지/게시판/공지/열람 가능한 답글/과제 설명에 연결된 학교 Canvas 파일도 찾습니다. 외부 서비스·제한된 자료는 결과 보고에서 확인하세요.
