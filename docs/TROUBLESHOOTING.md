# 문제 해결

저장 실패: 디스크 공간과 앱 지원 경로의 쓰기 권한을 확인하세요. 기존 데이터를 초기화하지 마세요. 노트는 저장 버튼으로 다시 시도하고 저장 완료 후 닫습니다.

Canvas 401: 토큰 재발급. 403: 학교 자료 권한 확인. 404: 기본 주소 확인. 429: 기다린 뒤 재시도. HTTPS CDN 이동은 지원하지만 HTTP 다운그레이드·반복·과도한 경로 및 크기 불일치는 거부합니다. 이미 가져온 자료는 유지됩니다.

PDF 텍스트가 선택되지 않음: 스캔 문서는 이미지일 수 있습니다. OCR은 이 버전에서 지원하지 않습니다. 암호 PDF 전용 입력 UI는 아직 없습니다.

백업 거부: 손상/누락 파일·상위 경로·체크섬 불일치·1GB 한도를 확인하세요. 기존 파일과 바이트가 다른 동일 경로를 덮어쓰지 않습니다. 안전한 별도 작업 공간에서 검토하세요.

Windows 실행 경고: 현재 코드 서명 인증서가 없습니다. 게시된 체크섬과 배포 출처를 확인하세요. Android 업데이트 실패: 이전 앱과 서명이 다른지 확인합니다. 앱 삭제 전 백업을 확보하세요.
