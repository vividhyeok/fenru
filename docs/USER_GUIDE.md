# 사용자 설명서

앱에 포함된 [상세 안내](../assets/help/guide.md)를 확인하세요. 앱에서는 설정 → 도움말 센터에서 같은 안내를 오프라인으로 볼 수 있습니다.

자료를 가져오면 원본과 별도로 복사됩니다. 라이브러리 메뉴에서 이름/폴더/태그를 수정하고, PDF에서 책갈피와 페이지 메모를 추가하세요. 노트는 Markdown 자동 저장이며 미리보기를 지원합니다. 플래너에 목표와 날짜를 입력하고 완료를 체크할 수 있습니다.

다른 기기로 이동하려면 설정 → ZIP 백업 후 대상 기기에서 백업 병합 복원을 사용합니다. ZIP에 개인 자료가 포함되며 암호화되지 않습니다. 외부 AI로 문서를 자동 업로드하거나 웹 구독 기능을 우회하지 않습니다.

PDF 도구줄의 읽기 메뉴에서 펜 필기·자유 형광펜·직선 밑줄을 선택하세요. 이동/텍스트 선택은 읽기로 돌아갑니다. 필기는 원본 PDF를 변경하지 않고 앱에 별도로 저장하며 ZIP 백업에 포함됩니다. 상단 정리 노트 버튼은 같은 자료 노트를 재사용합니다. 넓은 화면에서는 자료 옆에서 편집하고, 작은 화면에서는 노트 화면으로 이동합니다.

질문의 참고 범위·모델·이전 대화·연결 노트는 대화 메뉴에서 확인합니다. 노트로 저장 후 완료 메시지의 열기 버튼을 누르세요. 패널을 넓게 보거나 나란히 전환해도 작성 중 질문을 유지합니다. 입력창의 +는 한 문제씩 복습 등의 문장을 준비하며 자동 전송하지 않습니다.

Office/한글 문서는 원본 저장 후 PDF 변환을 시도합니다. Windows에 LibreOffice 또는 해당 Word/PowerPoint/한글이 필요하며, 한글은 파일 접근 허용이 필요할 수 있습니다. 실패 원본 화면에서 PDF로 변환·재시도합니다. Android에는 변환 엔진이 없으므로 원본 앱에서 PDF로 저장하거나 Windows 변환 PDF를 백업으로 옮기세요. Canvas 자료는 과목 가져오기를 다시 실행하면 새 탐색 경로의 첨부도 확인합니다.
