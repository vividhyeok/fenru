# 사용자 설명서

앱에 포함된 [상세 안내](../assets/help/guide.md)를 확인하세요. 앱에서는 설정 → 도움말 센터에서 같은 안내를 오프라인으로 볼 수 있습니다.

자료를 가져오면 원본과 별도로 복사됩니다. 라이브러리 메뉴에서 이름/폴더/태그를 수정하고, PDF에서 책갈피와 페이지 메모를 추가하세요. 노트는 Markdown 자동 저장이며 미리보기를 지원합니다. 플래너에 목표와 날짜를 입력하고 완료를 체크할 수 있습니다.

다른 기기로 이동하려면 설정 → ZIP 백업 후 대상 기기에서 백업 병합 복원을 사용합니다. ZIP에 개인 자료가 포함되며 암호화되지 않습니다. 외부 AI로 문서를 자동 업로드하거나 웹 구독 기능을 우회하지 않습니다.

PDF 도구줄의 읽기 메뉴에서 펜 필기·자유 형광펜·직선 밑줄을 선택하세요. 이동/텍스트 선택은 읽기로 돌아갑니다. 필기는 원본 PDF를 변경하지 않고 앱에 별도로 저장하며 ZIP 백업에 포함됩니다. 상단 정리 노트 버튼은 같은 자료 노트를 재사용합니다. 넓은 화면에서는 자료 옆에서 편집하고, 작은 화면에서는 노트 화면으로 이동합니다.

질문의 참고 범위·모델·이전 대화·연결 노트는 대화 메뉴에서 확인합니다. 노트로 저장 후 완료 메시지의 열기 버튼을 누르세요. 패널을 넓게 보거나 나란히 전환해도 작성 중 질문을 유지합니다. 입력창의 +는 한 문제씩 복습 등의 문장을 준비하며 자동 전송하지 않습니다.

Office/한글 문서는 원본 저장 후 PDF 변환을 시도합니다. Windows에 LibreOffice 또는 해당 Word/PowerPoint/한글이 필요하며, 한글은 파일 접근 허용이 필요할 수 있습니다. 실패 원본 화면에서 PDF로 변환·재시도합니다. Android에는 변환 엔진이 없으므로 원본 앱에서 PDF로 저장하거나 Windows 변환 PDF를 백업으로 옮기세요. Canvas 자료는 과목 가져오기를 다시 실행하면 새 탐색 경로의 첨부도 확인합니다.


## 빠른 연결과 PDF 참조 범위 (개선 작업)

첫 실행 화면에서 Canvas 주소/토큰과 AI 제공자/API 키/모델을 입력하고 ‘Fenru 시작하기’를 누르면 저장합니다. 연결은 선택 사항입니다. 사용 한도는 고급 설정에서 조정합니다. 홈의 ‘학교 · AI 빠른 연결’로 미완료 연결을 이어갈 수 있습니다. 이미 저장한 주소, 제공자, 모델은 다시 입력하지 않습니다.

과목을 연 뒤 상단 ‘파일 추가’로 여러 자료를 해당 과목에 바로 넣습니다. 같은 폴더의 동일 파일은 중복 생성하지 않으며 다른 폴더의 자료는 유지합니다.

PDF 질문 패널의 ‘PDF 참조 범위 선택’에서 PDF 전문, 현재 페이지, 선택 문장, 지정 페이지(예: 1-5, 8), 전체에서 관련 부분 검색을 구분합니다. 전문은 추출 가능한 모든 페이지 텍스트를 포함하며 검색 모드의 발췌 6개 제한을 적용하지 않습니다. 참조 모드와 문서별 페이지 범위를 기억합니다. 300,000자를 넘으면 범위를 줄이도록 안내하며 조용히 잘라 보내지 않습니다. 제공자의 컨텍스트 및 설정한 일별 토큰 상한도 적용됩니다. 스캔/이미지는 OCR 없이 읽을 수 없고 누락 안내를 표시합니다.

필기 도구에서 ‘지우개 · 획 지우기’를 선택해 필기 획을 지웁니다. 지운 획도 실행 취소/다시 실행이 가능합니다. 펜 버튼의 보조 버튼 이벤트 또는 뒤집힌 펜 이벤트가 전달되면 누르는 동안 지우개로 전환합니다. S펜 실제 기기의 이벤트 전달은 별도 확인이 필요합니다.


## 동기화와 시험 준비

과목 화면의 ‘선택 과목 동기화’는 처음 선택한 과목을 다음에도 기억합니다. 기존에 가져온 과목도 기본 동기화 대상으로 이어받습니다. 바꾸려면 ‘동기화 과목 변경’을 누르세요. 정상 완료는 확인 창을 매번 띄우지 않으며 ‘최근 동기화 결과’에서 확인합니다.

학교 API가 허용하는 공지 본문·게시판과 공개 답글·강의 페이지·과제 설명·강의계획(제공되는 경우)을 텍스트 자료로 저장하고 첨부파일도 함께 찾습니다. 내용이 같으면 중복 저장하지 않고, 수정된 글은 최신 버전을 참조합니다. 과목 화면에서 파일/공지/과제/페이지/게시판/강의계획을 골라 관리합니다. 학교가 접근을 제한하거나 Canvas API로 제공하지 않는 항목은 결과에 경고를 남깁니다.

과목 질문의 ‘시험 준비’를 사용하거나 ‘시험 나올 거 짚어줘’라고 질문하세요. 시험 관련 공지/과제 근거와 관련 강의자료를 함께 찾습니다. 교수자가 밝힌 시험 정보와 AI가 제안하는 공부 우선순위를 구분하도록 요청합니다. 실제 출제 문제를 알아내는 기능은 아닙니다.

필기 기본값은 펜·마우스로 필기하고 손가락으로 이동·확대하는 방식입니다. 위쪽 도구줄의 손가락/펜 전환으로 손가락 필기도 선택할 수 있습니다. 읽기·펜·형광펜·지우개·실행 취소·다시 실행을 도구줄에서 바로 누릅니다. 펜 굵기와 색상, 입력 방식도 기억합니다.
