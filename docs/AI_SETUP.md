# AI 연결

현재 개발 버전은 OpenAI 및 DeepSeek API 요청을 구현하지 않았습니다. 키 없이 로컬 기능을 사용할 수 있습니다. 키를 채팅이나 이슈에 올리지 마세요.

향후 BYOK 연결은 OS 보안 저장소, 연결 테스트, 모델 목록/직접 ID 설정, 문서 전송 범위 확인, 요청 취소/스트리밍/사용량 기록을 제공해야 합니다. ChatGPT 구독과 API 청구는 별개입니다. 실제 유료 API 테스트는 사용자가 승인한 키로만 수행합니다. 환경에서 발견한 개발자 키를 배포 앱에 포함하지 않습니다.

OpenAI 공식 문서 확인: https://developers.openai.com/api/reference/resources/responses/methods/create
DeepSeek 공식 문서: https://api-docs.deepseek.com/

출처 기반 답변을 구현하기 전에는 페이지 번호나 검색 근거를 임의로 생성하지 않습니다.
