# AI 연결

설정 → AI API 키·모델 설정에서 OpenAI 또는 DeepSeek를 선택하고 새 키를 입력합니다. 연결 확인·모델 조회 후 텍스트 생성 모델을 선택하거나 모델 ID를 직접 입력한 뒤 저장하세요. 빈 키 입력은 기존 보관 키를 유지합니다. 연결 해제는 해당 제공자의 키를 삭제하고 대화는 유지합니다. 키 없이 로컬 기능을 사용할 수 있습니다. 키를 채팅이나 이슈에 올리지 마세요.

키는 OS 보안 저장소에 보관합니다. OpenAI Responses API(store=false)와 DeepSeek Chat Completions API를 사용합니다. 스트리밍·취소·부분 답변 보관, 메시지 복사·노트 저장, 제공자가 보고한 사용량 기록을 구현했습니다. ChatGPT 구독과 API 청구는 별개입니다. 개발자 환경 키를 배포 앱에 포함하지 않습니다.

별도 AI 메뉴 대신 과목과 자료 안에서 질문합니다. 과목 → 과목 열기에서는 해당 과목 자료 목록과 질문 패널을 함께 보며, 자료 목록 메뉴의 ‘이 자료에 질문’ 또는 PDF 리더 상단 ‘자료 질문’으로 개별 자료에 질문합니다. 과목/자료 ID별로 대화가 분리되어 재실행 후 이어집니다. 다른 과목·이전 버전·휴지통 자료는 과목 질문의 근거에서 제외합니다.

자료 전체 또는 과목에 질문하면 기기에서 PDF/텍스트의 본문을 추출하고 질문 키워드와 관련된 발췌 최대 6개/12,000자를 선택합니다. 출처는 문서 ID·버전 해시·실제 페이지로 보존하고 답변 아래 출처 버튼으로 원문을 다시 엽니다. ‘전송할 참고 자료 미리보기’는 유료 API 호출 없이 근거를 확인합니다. 읽지 못한 자료는 미리보기와 답변의 제외 자료 안내에 표시합니다. 자료 전체를 모델에 통째로 보내거나 완전한 전체 요약을 보장하는 방식이 아닙니다. 키워드 일치가 없으면 문서별/페이지별 대표 발췌를 고릅니다. 임베딩 의미 검색과 OCR, PPTX/DOCX 본문 추출은 아직 없습니다.

PDF에서는 질문 패널의 참고 범위를 ‘자료 전체’ 또는 ‘선택 문장 / 현재 페이지’로 바꿀 수 있습니다. 좁은 화면에서는 자료 질문을 누를 때 범위를 선택합니다. 선택 영역 메뉴의 ‘선택 문장 질문’은 그 문장을 고정해서 전송하며, 여러 페이지 선택은 정확한 출처를 위해 거부합니다. 최근 메시지는 최대 20개를 보냅니다. 본문 캐시는 작업 공간의 text-index에 버전 해시별로 저장하며 원본과 별도로 재생성할 수 있습니다. 캐시가 ZIP 백업으로 중복 전송되지는 않습니다.

출력 한도 256~8192, 일별 토큰 상한을 설정합니다. 일별 기록과 보수적 예상 입력 크기로 요청을 제한하지만 금액 예산은 아닙니다. 실패·취소 시 사용량이 누락될 수 있으며 실제 청구는 제공자 대시보드 기준입니다. 자동 유료 요청 재시도는 없습니다.

2026-10-21 개발 환경 기존 키 재사용을 사용자에게 승인받아 공식 /v1/models를 요청했으나 HTTP 401이었습니다. 따라서 실제 생성 API 성공은 검증하지 못했습니다. 새 키는 사용자 앱 설정에 직접 입력합니다. SSE 처리와 비밀을 제외한 오류 메시지는 모의 HTTP로 검증했습니다.
