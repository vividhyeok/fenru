# 사용자 흐름

과목 → 과목 열기 → 자료 목록과 과목 질문 패널. 과목 자료의 PDF/텍스트에서 관련 발췌를 찾으며 대화는 그 과목에 저장합니다. 모바일에서는 ‘이 과목 자료에 질문하기’로 같은 범위의 질문 화면을 엽니다.

자료 → PDF 리더 → 자료 질문. 넓은 화면에는 오른쪽 질문 패널이 기본 표시됩니다. 자료 전체 또는 현재 페이지를 고르거나, 선택 문장 메뉴 → 선택 문장 질문을 사용합니다. 모바일에서는 질문 범위를 먼저 고릅니다. 답변 아래 출처 버튼 → 실제 PDF 페이지로 돌아갑니다. 참고 미리보기는 외부 생성 요청 없이 사용할 수 있습니다. 독립 AI 메뉴는 제공하지 않습니다.

PDF 도구 막대 → 페이지/목차/주석 탐색, 확대/축소·맞춤, 본문 검색/결과 이동, 읽기 색상, 주석 색상·실행 취소/다시 실행. 모든 주석은 원본 PDF와 별도로 보관합니다.

시작 → 5단계 안내 또는 연결 없이 시작 → 홈 → 파일 가져오기 → 라이브러리 → 자료 열기 → 페이지/주석 저장. 홈의 이어서 읽기에서 마지막 문서를 재개합니다.

자료 메뉴 → 연결 노트 → Markdown 입력 → 저장됨 상태 확인 → 뒤로. 저장 실패 시 노트 화면을 유지하고 재시도합니다.

설정 → Canvas 주소/토큰 → 연결 테스트 → 과목 → 가져오기 → 과목 선택 → 파일/과제 보관. 실패 전 보관한 자료는 유지하며 오류 원인을 banner로 제공합니다.

설정 → ZIP 백업 → 파일 저장. 다른 기기 → 백업 병합 → 경로/체크섬 검사 → 객체 병합 → 충돌 복사본 검토. 자동 클라우드 연결로 오인시키지 않습니다.

자료 메뉴 → 휴지통 → 라이브러리 휴지통 → 복구. 일반 주석/노트/일정의 휴지통 표시 UI는 추가 작업이 필요합니다.


alpha.7 공부 작업: PDF 도구줄의 읽기 메뉴에서 펜/형광펜/밑줄을 고릅니다. 이동·텍스트 선택은 읽기로 돌아갑니다. 상단 정리 노트는 같은 자료 노트를 재사용하고 자동 저장 상태를 표시합니다. 넓은 화면에서는 자료 옆, 작은 화면에서는 노트 편집 화면입니다. 질문 버튼으로 질문 패널을 다시 표시합니다. 패널 넓게 보기는 작성 중 내용을 보존합니다.
질문 UI: 제목줄/메시지/입력창을 기본으로 유지하고 참고 범위·모델·이전 대화·연결 노트는 메뉴에서 엽니다. 추천 도구는 입력을 도와주며 자동 API 요청을 하지 않습니다. 답변 저장 후 완료 메시지의 열기 또는 노트 열기 버튼을 사용합니다. 출처·사용량은 답변 아래를 펼쳐 봅니다.
문서 가져오기: 원본 보관→로컬 PDF 변환 시도→성공하면 PDF와 원본 연결, 실패하면 원본/실패 상태/재시도 제공. Android에서는 변환 엔진 부재를 안내하고 원본을 보관합니다.
