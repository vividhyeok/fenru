# 보안 및 개인정보

- 문서/노트는 앱 지원 경로의 SQLite와 파일에 저장합니다. 로컬 DB와 파일 및 ZIP은 암호화되지 않습니다.
- Canvas 토큰은 flutter_secure_storage가 제공하는 OS 보안 저장소에 보관합니다. DB payload·일반 preferences·백업에 저장하지 않습니다. 설정의 연결 해제로 삭제합니다.
- Canvas HTTPS 기본 주소만 허용합니다. 인증정보를 포함한 URL, 경로/쿼리가 있는 기본 주소는 거부합니다. API 페이지네이션은 동일 origin으로 제한하며 리다이렉트를 거부합니다. 파일 다운로드는 별도 검증된 HTTPS 리다이렉트 처리를 사용합니다.
- 외부 다운로드 URL에 Canvas 토큰을 보내지 않습니다. 동일 Canvas origin일 때만 헤더를 붙입니다. 로그에 요청 헤더를 출력하는 HTTP interceptor를 사용하지 않습니다.
- 제주대 LearningX는 Canvas 공식 sessionless launch가 반환한 동일 학교 주소의 서명 양식을 정확한 `/learningx/lti/modulebuilder` 경로에만 제출합니다. 인증 양식/단기 토큰/학교 쿠키는 메모리에서만 사용하며 Commons로 보내지 않습니다. Commons 문서 정보는 검증된 `common.jejunu.ac.kr`에서 조회하고 다운로드 주소의 출처를 다시 검사합니다. 강의 항목 뷰어·영상·퀴즈·설문·출석 완료 요청은 자동 실행하지 않습니다. 문서 다운로드 자체는 학교 접속 기록에 남을 수 있습니다.
- ZIP의 절대/상위 경로·드라이브 문자·symlink와 미지원 항목을 거부하고 파일 해시를 검증합니다. 신뢰하지 않는 ZIP을 완전히 안전한 샌드박스에서 처리하는 구조는 아니며 메모리 압축 폭탄에 대한 추가 스트리밍 방어가 필요합니다.
- 사용량/광고/추적 SDK가 없습니다. AI 질문에는 최근 메시지 최대 20개와 사용자가 포함을 선택한 PDF 컨텍스트를 전송합니다. 키는 OS 보안 저장소에 보관하고 백업에서 제외합니다. OpenAI 요청은 store=false이며 제공자의 API 데이터 정책은 별도로 적용됩니다. Drive 연동은 아직 없습니다.
- API 오류 본문/인증 헤더를 로그나 화면에 그대로 반영하지 않습니다. 실제 모델 출처 링크는 제공한 ID·페이지와 일치해야 열립니다. 모델 출력이 파일·명령을 자동 실행하지 않습니다.
- 과목 질문은 같은 과목의 최신 자료만 참조하며 다른 과목·휴지통·이전 버전은 제외합니다. 자료 질문은 해당 자료 ID로 제한합니다. PDF/텍스트 추출과 버전별 text-index 캐시는 로컬 작업 공간에서 처리하고 선택된 발췌만 AI 제공자에게 전송합니다. 텍스트 캐시는 암호화되지 않으며 재생성 가능한 파생 데이터로 ZIP 백업에서 제외됩니다. 참고 미리보기는 외부 생성 API를 호출하지 않습니다.
- Android 배포 서명 키는 GitHub Secrets와 Git 제외 로컬 JKS에 보관하고 비밀번호는 Windows DPAPI로 보호합니다. 공개 인증서 지문은 비밀이 아닙니다. PR에는 배포 서명 Secrets를 전달하지 않습니다.

취약점 보고에는 개인 자료/키/토큰을 넣지 마세요. 공유 기기에서는 OS 계정 보호와 디스크 암호화를 권장합니다. 정식 서명과 배포용 OAuth 설정은 별도 자원이 필요합니다.
