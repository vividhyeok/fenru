# 보안 및 개인정보

- 문서/노트는 앱 지원 경로의 SQLite와 파일에 저장합니다. 로컬 DB와 파일 및 ZIP은 암호화되지 않습니다.
- Canvas 토큰은 flutter_secure_storage가 제공하는 OS 보안 저장소에 보관합니다. DB payload·일반 preferences·백업에 저장하지 않습니다. 설정의 연결 해제로 삭제합니다.
- Canvas HTTPS 기본 주소만 허용합니다. 인증정보를 포함한 URL, 경로/쿼리가 있는 기본 주소는 거부합니다. 페이지네이션은 동일 origin으로 제한하며 리다이렉트를 거부합니다.
- 외부 다운로드 URL에 Canvas 토큰을 보내지 않습니다. 동일 Canvas origin일 때만 헤더를 붙입니다. 로그에 요청 헤더를 출력하는 HTTP interceptor를 사용하지 않습니다.
- ZIP의 절대/상위 경로·드라이브 문자·symlink와 미지원 항목을 거부하고 파일 해시를 검증합니다. 신뢰하지 않는 ZIP을 완전히 안전한 샌드박스에서 처리하는 구조는 아니며 메모리 압축 폭탄에 대한 추가 스트리밍 방어가 필요합니다.
- 사용량/광고/추적 SDK가 없습니다. AI 및 Drive 연동이 없는 현재 버전은 학습자료를 해당 서비스에 전송하지 않습니다.

취약점 보고에는 개인 자료/키/토큰을 넣지 마세요. 공유 기기에서는 OS 계정 보호와 디스크 암호화를 권장합니다. 정식 서명과 배포용 OAuth 설정은 별도 자원이 필요합니다.
