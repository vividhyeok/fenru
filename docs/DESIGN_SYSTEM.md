# 디자인 시스템

Material 3, 중립 배경 #f6f7f9 / 다크 #111820, 기본 포인트 #234b80. ColorScheme.fromSeed로 정보 계층과 오류/선택 상태를 통일합니다. 장식용 그라데이션이나 과한 그림자를 사용하지 않습니다.

간격: 8/12/16/24/32. 기본 모서리 8, 카드 elevation 0 및 outlineVariant 테두리. 타이포그래피는 Material 스케일과 플랫폼 폰트를 사용합니다. 별도 폰트 파일을 배포하지 않습니다. 본문 16px 수준과 1.7 줄높이를 기본으로 합니다.

700px 이상 NavigationRail, 미만 5개 Bottom Navigation. Reader는 1000px 이상일 때 290px 주석 패널을 제공하고 좁은 화면에서는 bottom sheet를 사용합니다. Material 접근성 라벨과 툴팁을 사용합니다. 브랜드는 자체 제작 Canvas 사막여우 귀 실루엣입니다. 현재 플랫폼 앱 아이콘은 Flutter 생성 기본값이며 교체가 필요합니다.

접근성·큰 글꼴·고대비·키보드 및 실제 Android 회전 검증은 남아 있습니다. 영어 시스템 위젯 로케일은 지원하지만 앱 문자열은 한국어입니다.
