# Fenru 개발 프리릴리스

alpha.5 학습 흐름 개선: AI를 과목/자료에 통합했습니다. 과목 작업 공간과 PDF 리더에서 해당 범위의 자료에 질문하고 대화를 이어갑니다. PDF/텍스트를 기기에서 읽어 키워드에 맞는 근거 최대 6개/12,000자를 선택하며 실제 페이지로 돌아가는 출처 버튼과 참고 미리보기를 제공합니다. 완전한 전체 문서 요약이나 의미 검색/OCR은 지원하지 않습니다. 유료 생성 API의 실제 응답은 미검증입니다.

PDF 리더에 페이지 썸네일·목차·주석 패널, 확대/축소·너비/페이지 맞춤, 검색·이전/다음 결과, 읽기 색상, 주석 색상·현재 실행 중 생성한 하이라이트의 실행 취소/다시 실행을 추가했습니다. 넓은 화면에는 조절 가능한 자료 질문 패널이 기본 표시되고 모바일에서는 질문 범위를 선택합니다. Ctrl+F 검색, Ctrl +/- 확대/축소, Ctrl+0 너비 맞춤을 제공합니다.

alpha.4 Canvas/LearningX 수정: 과목 조회는 성공하지만 파일 목록이 401을 반환하는 학교 설정을 처리합니다. 토큰 유효성 재확인, 모듈 File 항목 탐색과 중복 제거, 제한된 파일/과제 건너뜀, 결과 보고를 추가했습니다. 제주대 LearningX는 Canvas의 서명된 주차별 학습 연결로 인증하고 첨부자료와 Commons 문서를 찾습니다. 실제 Dart 코드의 학교 자료 조회와 PDF 1개 다운로드를 검증했습니다. 원본 저장소가 다운로드 주소를 제공하지 않는 문서는 경고로 보고합니다. 일반 Pages 첨부와 다른 학교의 Commons 주소는 아직 지원하지 않습니다. 영상·퀴즈·설문·출석 완료 요청은 자동 실행하지 않습니다.

로컬 기능 검증을 위한 초기 개발 버전입니다. 전체 요구사항을 충족하는 완성품이 아닙니다.

자료 가져오기·PDF 열람/검색·하이라이트/밑줄·책갈피/페이지 메모·Markdown 노트·일정·검색·ZIP 백업/병합 복원을 포함합니다. OpenAI/DeepSeek BYOK 설정, 모델 조회, 스트리밍·취소·대화 보관과 PDF 페이지 컨텍스트를 제공합니다. 실제 AI 생성 성공은 미검증입니다(기존 개발 키 401). Canvas 연결은 사용자가 완료했으며 실제 파일/과제 가져오기는 아직 미검증입니다.

Google Drive 자동 동기화, 전체 라이브러리 RAG, 위젯, 시스템 알림, 영어 UI는 제공하지 않습니다. 대용량 ZIP은 메모리 제약이 있습니다. 중요한 자료는 별도로 백업하세요.

Windows는 서명되지 않은 설치 프로그램 및 Portable ZIP입니다. Android release.apk는 프로젝트 RSA 4096 키로 서명합니다. test-signed.apk가 별도로 제공되는 경우 이는 임시 테스트 서명입니다. 서로 다른 서명의 APK는 덮어 업데이트할 수 없습니다. 실제 플랫폼 통합 테스트 및 서명 검증 결과는 Actions와 구현 현황을 확인하세요. CI 성공은 모든 사용자 시나리오 검증을 의미하지 않습니다.

Windows: ZIP 전체를 풀고 실행 파일을 실행하세요. Android: APK 설치 권한을 허용한 뒤 설치하세요. 기존 데이터는 앱 지원 경로에 보관됩니다. 업데이트 전 설정에서 ZIP 백업을 만드세요. 다른 서명의 Android APK는 기존 앱 위에 업데이트할 수 없습니다.

키 입력: 설정 → AI API 키·모델 설정 → 제공자 → 새 API 키 → 연결 확인·모델 조회 → 모델 선택 → 저장. 비밀 키를 채팅이나 이슈에 올리지 마세요. Windows 기존 앱을 먼저 닫고 새 버전을 실행하세요. Canvas 연결 설정과 로컬 작업 공간은 유지됩니다.
