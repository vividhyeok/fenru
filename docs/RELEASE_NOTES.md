# Fenru 개발 프리릴리스

로컬 기능 검증을 위한 초기 개발 버전입니다. 전체 요구사항을 충족하는 완성품이 아닙니다.

자료 가져오기·PDF 열람·책갈피/페이지 메모·Markdown 노트·일정·검색·ZIP 백업/병합 복원 코드를 포함합니다. Canvas 파일/과제 가져오기는 실제 학교 계정에서 검증하지 않았습니다.

AI 및 Google Drive 자동 동기화, 영역 하이라이트, 위젯, 시스템 알림, 영어 UI는 제공하지 않습니다. 대용량 ZIP은 메모리 제약이 있습니다. 중요한 자료는 별도로 백업하세요.

Windows 파일은 서명되지 않은 Portable ZIP입니다. Android APK는 **테스트 키 서명**이며 정식 배포 키 서명이 아닙니다. 기기/GUI 실제 실행 검증 상태는 저장소 구현 현황을 확인하세요. CI 성공은 실제 모든 사용자 시나리오 검증을 의미하지 않습니다.

Windows: ZIP 전체를 풀고 실행 파일을 실행하세요. Android: APK 설치 권한을 허용한 뒤 설치하세요. 기존 데이터는 앱 지원 경로에 보관됩니다. 업데이트 전 설정에서 ZIP 백업을 만드세요. 다른 서명의 Android APK는 기존 앱 위에 업데이트할 수 없습니다.
