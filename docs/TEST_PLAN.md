# 검증 계획과 증거

alpha.5: unit/widget 40개 통과. 추가 검증은 과목 ID/원본 source 기반 범위 제한, 다른 과목/이전 버전/휴지통 제외, 뒷페이지 검색과 페이지 출처, 발췌 상한, 검색 취소, 모의 API 전송 내용/대화 저장/다른 자료의 대화 분리, 독립 AI 내비게이션 제거와 모바일 과목 진입, 세로/가로 키보드 레이아웃입니다. 실제 생성 API 비용은 발생시키지 않습니다. 플랫폼 통합 테스트는 리더 이전 본문 추출/캐시, 확대/맞춤/검색, 주석 Undo/Redo와 재오픈 보존을 검사하며 Windows에서는 실제 Flutter PDF 렌더를 테스트 문서로 캡처합니다.

자동 테스트: 노트 저장/FTS/휴지통/복구, 가져오기 복사/중복/페이지, DB 종료/재오픈, 백업 두 기기 동시 편집·멱등, Canvas URL 검증, 로컬 전용 온보딩 위젯. 테스트 파일을 작성한 사실과 테스트 성공은 다릅니다. 결과는 IMPLEMENTATION_STATUS.md 및 Actions에서 확인하세요.

추가 필수: 악성 ZIP 경로·체크섬·압축 폭탄·부분 쓰기 실패, Canvas 페이지네이션/401/403/429 mock, 동시 삭제/수정, v1→v2 마이그레이션, 노트 저장 실패 후 재시도, PDF 렌더/선택/주석 재실행, 좁은 화면/다크/큰 글꼴/수천 자료 성능.

실제 기기 시나리오: Windows 최초 실행→가져오기→PDF→노트→재실행, Android 동일 흐름, ZIP 이동 및 동시 편집, 실제 Canvas, 최종 AI/Drive 계정 연결, 위젯/공유/알림. 미구현 기능은 시나리오 통과로 표시하지 않습니다.

integration_test/local_flow_test.dart는 임시 작업 공간에서 온보딩 → PDF 가져오기 → 렌더 → 문장 선택 → 하이라이트/책갈피 → DB 종료/재오픈 후 보존을 확인합니다. CI는 Windows와 Android API 35 에뮬레이터에서 실행하며, 로컬 Android API 36.1에서도 통과했습니다. 사용자의 실제 작업 공간과 인증 정보는 사용하지 않습니다.

alpha.4의 unit/widget 테스트 32개는 쓰기 직렬화·재오픈·FTS·휴지통, 파일 복사/중복, 백업 체크섬/경로 검증과 동시 편집 병합/멱등성, Canvas 페이지네이션·외부 CDN 토큰 제거·HTTPS 제한·Files 권한 오류/인증 오류 구분·모듈 다운로드·부분 성공·로그인 HTML 거부, LearningX 서명 인증·첨부파일/Commons 경계·외부 인증정보 전송 차단, OpenAI/DeepSeek 스트림 파싱·오류 메시지 비밀 제외, API 키 입력 숨김, 로컬 온보딩, 밝기별 3개 화면 크기 레이아웃, Windows 중복 실행 잠금을 검증합니다. 위젯 렌더 이미지는 실제 OS 스크린샷과 구분합니다. 실제 API 생성·실물 기기·설치 프로그램 실행은 별도 검증 대상입니다. 학교 자료 조회/다운로드의 실제 증거와 한계는 IMPLEMENTATION_STATUS.md를 확인하세요.
